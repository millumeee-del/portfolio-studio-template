# 分享包检查

本包通过白名单复制应用源码与必要配置，重新生成所有示例内容和媒体。没有复制个人工程的 public、Git 历史、备份、登录缓存、发布状态、访客数据库、原作品、二维码、个人模型或字体二进制。

`npm run audit:share` 会检测发布目录中的环境文件、数据库、缓存、私钥、疑似 token、绝对用户路径以及非示例邮箱。它是保守的自动检查，不能识别将来上传照片里的脸、画面内文字或权利归属；使用者替换内容后仍应自己审阅。

后续创作时：
- 不提交 `.env`、`.dev.vars`、本地数据库、Cookie、凭据和账户 ID。
- 不把个人工程的历史直接推到模板仓库。
- 新上传的素材属于源内容，可以随源码发布，但请先检查内容与授权。
- 原始访客留言与撤回凭据属于运行时数据，不是演示数据。
